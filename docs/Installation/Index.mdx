# Installation

Lumunarr comes pre-built as a Docker image, which is the recommended way to run it. You can also download the source code and run it natively with Node.js.

:::note
Lumunarr is tested and supported on Linux and Windows, both natively and in Docker. Virtualized environments such as VMs, LXCs or other hypervisor-based setups may work but are not supported, since problems there usually come from the host setup rather than Lumunarr itself.
:::
